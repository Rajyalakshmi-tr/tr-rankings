# TR Rankings — Coming Soon

A simple static Coming Soon page for GitHub Pages.

## Files

- `index.html` — page structure
- `style.css` — responsive design and TR Rankings branding
- `script.js` — live countdown to December 11, 2026

## GitHub Pages

1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save.
7. Wait for GitHub Pages to publish the site.

The countdown will automatically update every second in the visitor's browser.
